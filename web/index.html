GFF3 validator

Check a GFF3 file against GFF3 1.26 in your browser, with the same engine as the gff3-validate command.

Your files stay on this computer

The validator runs inside this page (Python compiled to WebAssembly, Pyodide). Your annotation and genome files are read locally and are never uploaded. After the page has loaded, the only network requests are for the Python runtime and its packages from cdn.jsdelivr.net and for the validator itself from this site; the page's Content-Security-Policy blocks every other connection.

The genome is copied into the browser's memory (gzip genomes need about twice their uncompressed size while decompressed). A browser tab can usually use 1 to 2 GB, so genomes above a few hundred MB may fail; use the command line for large genomes.

Limits

Files are read in slices, so the annotation itself is not held in memory, but Python in the browser is slower than on the command line and a tab's memory is limited. See the README for measured sizes. The validator is a pre-release: only the rules marked implemented in the rule catalogue are checked, and the report lists what was not checked.
